# 三阶段提示词

提示词只执行当前阶段；进入条件由 `SKILL.md` 状态机和任务目录中的 `deck-spec.md` 决定。

## Prompt 1A：内容大纲

```text
基于已确认的源材料、使用场景、受众和页数预期，提炼一套逻辑完整的 PPT 内容大纲。

要求：
1. 每页只承载一个主要结论，列出页码、标题、核心结论、必须准确出现的文字/数据及来源。
2. 不得虚构材料中没有的数据、案例、人物或引语；不确定内容列入待确认项。
3. 检查整体叙事是否适合使用场景和受众，避免直接搬运原文或机械套用固定目录。
4. 只输出内容大纲和待确认项，不生成风格图片，不决定用户尚未授权的内容。

将大纲写入 deck-spec.md 后展示给用户，并停止等待确认。
```

## Prompt 1B：四套幻灯片浏览视图

```text
只使用 deck-spec.md 中已经确认的内容大纲生成风格方案。

从完整大纲选择同一组 6–8 个代表页；总页数不超过 8 页时展示全部页面。分别生成四张横向“幻灯片浏览视图”总览图，每张以 3×2、4×2 或相近网格展示同一组迷你 16:9 幻灯片。

四套方案必须使用完全相同的页序、页面类型、标题、数字、核心内容和信息层级，只改变配色、字体气质、网格、版式系统、图形语言和素材风格。每张总览内部只能有一种统一风格。

不得输出四张单页，不得把四套方案拼成一张四宫格，不得用纯文字风格说明代替图片。有参考但未锁定时，以参考的品牌约束为基础做四种不越界的演绎。

独立保存方案 1–4，并为每套写一句客观特点。不要继续生成完整页面。
```

## Prompt 2：完整图片版与 Page Spec

```text
根据已确认的内容大纲和锁定视觉规范，先建立符合 Page Spec v1 的 page-spec.json，再逐页生成完整的 16:9（或规格指定比例）PPT 页面图片。

Page Spec 对每页记录：
- 已确认内容版本、用户确认原文和风格决策授权；
- 稳定页面 ID、页码、标题和核心结论；
- 所有准确文字、数字、表格/图表数据及来源；
- 语义元素稳定 ID、确认状态、原生/图片意图和可选 bbox_hint；
- 页面视觉简报、图片文件、状态与实际生成提示词。

每一页生图提示必须重复提供：
1. 锁定的配色、字体气质、字号层级、网格、留白、图形语言、素材风格、页码样式和禁用项；
2. Page Spec 中当前页的准确文字、数据、结论和来源约束；
3. 当前页页码和总页数；
4. 当前页允许出现的视觉对象、布局重点和独立素材意图。

要求：
- 一次只生成当前页，不自行增删页面或改写已确认内容。
- 文字、数字、日期和单位必须准确，不得乱码、错字、漏字、重复、裁切或溢出。
- 不得为了美观删减关键事实或补充来源中没有的内容。
- 跨页保持同一视觉系统，但版式服从内容，不机械复制同一网格。
- 文件按 01-title.png、02-title.png 的零填充格式保存。
- 验收失败只重做当前页，不连带重做已验收页面。
- 每页完成后把最终文件、状态、提示词和位置提示写回 Page Spec。

同一页文字连续两次仍不准确时，停止生图文字重试：生成无字视觉背景，再程序化叠加 Page Spec 中的准确文字，输出最终栅格页面。
```

### Prompt 2A：无字背景兜底

```text
为 {画布} 演示文稿生成当前页的无字视觉背景。
严格沿用 {锁定视觉规范}，保留 {不可移动的背景内容} 和准确的信息留白。
不得包含标题、正文、数字、数据标签、页码，或 Page Spec 中标记为独立素材的主体。
不新增装饰，不改变已确认布局。
```

## Prompt 3：Page Spec 驱动的可编辑还原

```text
以 page-spec.json 为语义事实源、指定页面图片为视觉事实源，还原 Scene v1 并编译可编辑 PPTX。保持页序、比例、内容、排版、视觉重心和遮挡关系，不重新设计。

每次只处理 1–3 页：
1. 直接复用 Page Spec 中已确认/来源可验证的页面与元素 ID、文字、数据、来源和原生/图片意图，不重新 OCR 或改写这些内容；只对 `unresolved` 项继续核验。
2. 从页面图片补齐精确坐标、层级、样式、图片主体、背景和遮挡；记录来源与置信度。
3. Page Spec 与图片冲突时记录具体差异并请求确认，不静默覆盖任一方。
4. 标题、正文、数字、页码、简单形状/线、表格和有可靠数据的图表使用原生对象。
5. 照片、人物、产品和复杂插画作为独立图片对象；separate_asset 为 true 的对象必须单独交付。
6. 从背景移除所有原生化文字与独立主体，只补全露出的背景。所有编辑从原始基准页开始，不串联编辑上一轮结果。
7. 原始整页图片只用于比对，不得充当可编辑版底图。
8. 复杂插画内部仍是像素；被遮挡区域若由 AI 补全，明确记录范围。

完成每批后编译、审查并渲染。只修有问题的 Scene 元素或素材，保留其他稳定 ID、页序、样式和层级。
```

### Prompt 3A：独立主体

```text
以 {原始基准页} 为唯一参考，提取或重建 Page Spec 中的 {元素 ID 与主体描述}。
保持身份、姿态、颜色、比例、光照和原始画布位置。输出真正带 alpha 的透明 PNG，只保留该主体及归属它的阴影/效果。
保持原画布尺寸；不得自动紧贴裁边，不添加文字、底板、棋盘格或其他对象。遮挡处只做最小补全并记录。
```

### Prompt 3B：背景清理

```text
以 {原始基准页} 为参考，从背景移除 {全部原生化元素和独立主体 ID 清单}。
只补全移除后露出的背景，保持其余结构、纹理、光照、尺寸、颜色和留白。
不得重排布局、移动剩余对象、改写文字或新增内容。
```

### Prompt 3C：局部修改

```text
只修改 {slide-id}/{element-id} 的 {文字/颜色/几何/图表数据/素材}。
先同步 page-spec.json；再修改 scene.json 或对应素材，保留其他对象 ID、页序、样式和层级。
文字、几何或数据修改不重新生图；图片内容变化只重做对应素材，然后重新编译并审查受影响页面。
```
