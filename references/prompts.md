# 三段核心提示词

以下提示词提取自小黑盒社区教程《青年大学习AI版：零基础用GPT5.6做精美可编辑PPT》（作者：玩家22186848），参考 B 站 UP 主「一往无前河井」的学术 PPT 制作流程。

---

## Prompt 1: 内容提炼与风格设计

用于让 AI 读懂书籍/文字材料，提炼核心内容，并生成四张不同风格的预览图。

### 开始前询问（必做）

在执行 Prompt 1 之前，**必须先向用户确认以下信息**，再开始后续流程：

```
请确认以下信息，我好开始制作 PPT：

1. 源材料：你要做成 PPT 的书籍/文档是什么？（请上传 PDF 或粘贴文字）
2. 参考风格：你是否有喜欢的 PPT 模板或参考风格图片？（如有请上传，我会参考其风格；如无也没关系，我会生成4套不同风格供你选择）
3. 使用场景：这份 PPT 用于什么场合？（课堂汇报 / 读书分享 / 组会 / 项目汇报 / 比赛路演 等）
4. 页数预期：大约需要多少页？（不确定的话我来根据内容推荐）
```

### 主提示词

```
请基于我上传的源材料（PDF / 文字资料），结合前面确认的使用场景，制作一份PPT演示文稿，要求如下：

请深入阅读并理解源材料中的核心内容，提炼作者背景、写作背景、全文结构、主要观点、重点章节、典型案例、经典语句、现实意义与启示，形成一套逻辑完整、重点清晰的汇报内容。

PPT整体风格要求专业、美观、清新，适合正式场合展示。如我提供了参考PPT图片，请模仿其配色、字体、版式、素材风格和视觉元素。

请避免大段文字堆砌，每页突出一个核心观点，重点展示材料中的核心内容、重要结论和最值得分享的思想。可以加入结构图、章节关系图、时间轴、人物关系图、流程图、重点总结页等可视化内容，并搭配与主题相关的图片和素材。

在生成最终PPT文件前，请先使用 AI 图像生成能力，分别生成四张不同风格的PPT预览图，方便对比查看。四套方案的内容结构保持一致，但主题颜色、排版方式和视觉风格需要有所区别，同时都要符合专业、美观、简洁的要求。

生成预览后先暂停，等待我选定其中一套风格，再根据选定方案制作完整的最终PPT文件。
```

**使用要点：**
- **必须先完成"开始前询问"，再执行主提示词**
- 源材料（PDF/文字）为必需项；参考模板图片为可选（如有则作为风格参考）
- 生成预览后暂停，等待用户选择

## Prompt 2: 生成完整图片版PPT

用于在用户选定风格后，逐页生成完整的 PPT 页面图片并合并为 .pptx 文件。

```
根据我选定的风格模板，使用 AI 图像生成能力逐页生成 PPT 页面图片，随后将所有页面图片拼合为完整 PowerPoint，并输出可下载的 .pptx 文件。
```

如果 AI 未能一次性输出 .pptx 文件，可追加指令：

```
给我提供可以下载的.pptx下载包。
```

**使用要点：**
- 多页 PPT 可能需要分多轮生成，每轮生成一页
- 最终需将所有页面图片合并为 .pptx 文件

## Prompt 3: 图片PPT还原为可编辑PPTX

用于将图片版 PPT（每页是一整张图片）逐页还原为可编辑的 PPTX 文件。采用"复杂视觉保真 + 主要文字可编辑"的混合还原策略。

```
请把这个PPT的指定页还原成16:9的可编辑PPTX文件。

【核心目标】
采用"复杂视觉保真 + 主要文字可编辑"的混合还原策略。
优先保留原图的整体设计质感、构图、视觉完成度和高级感，同时保证主要文字可以在PPT中直接编辑。
不要将整页简单铺成一张背景图。

【还原原则】
先识别页面结构，将页面内容拆分为：
1. 复杂视觉资产层
2. 可编辑信息层

复杂视觉资产层可优先从原图中裁切或提取为高清图片，并嵌入PPT，包括：
- 品牌Logo、商标、产品UI、人物、商品图、官方图标；
- 照片、插画、3D图、复杂背景、纹理、光影、玻璃拟态、金属质感；
- 复杂图表、复杂流程图、循环图、拼图等高复杂度视觉区域。

可编辑信息层尽量使用PPT原生元素重新搭建，包括：
- 主标题、副标题、正文段落；
- 金句、关键数字、关键词；
- 结论框文字、注释文字、页脚说明、章节名和页码；
- 简单线条、分隔线、基础几何图形、轻量标签、按钮、色块、基础表格和简单图表。

主要文字必须尽量使用PPT原生文本框重新制作，不得为了视觉保真而将所有文字压缩成图片。

复杂视觉区域中的小字，如果单独拆分会明显破坏画面质感，可以保留为图片，但需要在最终说明中明确标注。

【文字处理要求】
可编辑文字应尽量匹配原图的字体气质、字号层级、字重、颜色、行距、字距、对齐方式和具体位置。

如果无法准确识别原图字体，请选择最接近原图风格的系统字体：
- 中文：黑体、思源黑体、微软雅黑等；
- 英文及数字：选择接近原图的无衬线字体或衬线字体。

如果需要将原图中的文字改为可编辑文本，应先使用背景色、渐变近似或局部遮罩覆盖原文字，再叠加新的可编辑文本，避免出现文字重影。

不得出现明显错字、漏字、换行错误、文本溢出、文字重叠或位置漂移。

【设计还原要求】
保持原图的版式比例、视觉重心、阅读顺序和留白节奏。

保持原图的颜色、对比度、明暗关系、光源方向、阴影强度和空间层次。

复杂视觉区域应保留原始质感，不要替换成低质感的PPT默认图形、默认图标、默认阴影或模板化卡片。

所有元素的位置、大小、层级、裁切方式、圆角、描边、阴影、透明度和对齐关系都应尽量贴近原图。

图表数据如果无法准确反推，可以按照原图的视觉比例进行近似重建，并在最终说明中标注"数据为视觉近似"。

【输出要求】
1. 输出一份16:9比例的可编辑PPTX文件；
2. 同时渲染该页PPT的预览图，并与原始图片进行视觉对照；
3. 如果预览图与原图在质感、比例、间距、颜色、层级或整体观感方面存在明显差距，应继续迭代修改，不能在第一次生成后直接结束；
4. 确保文件可以在Microsoft PowerPoint中正常打开和继续编辑。

完成后请简要说明：
- 哪些元素被还原为可编辑文本、形状或图表；
- 哪些元素是从原图裁切或嵌入的高清图片；
- 哪些文字因为位于复杂视觉区域而保留为图片；
- 是否存在字体替代或图表数据近似的情况。

请先只完成一页并输出文件，不要一次性处理整套PPT。待我确认该页的还原质量和技术路线后，再使用相同标准逐页还原后续页面。
```

**使用要点：**
- 每次只处理一页，最多不超过三页，否则拆分效果不理想
- 该提示词同样适用于机制图、通路图等复杂图表的元素拆分
- 核心策略：复杂视觉保留为图片 + 主要文字转为原生文本框
