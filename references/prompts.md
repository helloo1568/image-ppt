# 三阶段提示词

这些提示词只执行当前阶段，不负责判断是否能进入该阶段。阶段门禁以 `SKILL.md` 状态机和任务目录中的 `deck-spec.md` 为准。

## Prompt 1：内容提炼与四套幻灯片浏览视图

```text
基于已确认的源材料、使用场景、受众和页数预期，提炼一套逻辑完整的 PPT 大纲。

要求：
1. 每页只承载一个主要结论；保留必须准确出现的人名、日期、数字、单位、引语及来源。
2. 不得虚构材料中没有的数据、案例或事实；不确定内容写入待确认项。
3. 从完整大纲选择同一组 6–8 个代表页用于风格比较；总页数不超过 8 页时展示全部页面。
4. 分别生成四张横向“幻灯片浏览视图”总览图。每张图以 3×2、4×2 或相近网格展示同一组迷你 16:9 幻灯片，代表一套完整设计方向。
5. 四套方案使用完全相同的页序、页面类型、标题、数字、核心内容和信息层级，只改变配色、字体气质、网格、版式系统、图形语言和素材风格。
6. 每张总览内部只能有一种统一风格。不得输出四张单页；不得把四套方案拼成一张四宫格；不得用纯文字风格说明替代图片。
7. 有参考模板时，以其品牌和视觉约束为基础做四种有区分度但不越界的演绎。

独立保存方案 1、2、3、4，并为每套写一句客观特点。不要继续生成完整页面。
```

## Prompt 2：生成完整图片版 PPT

```text
根据 deck-spec.md 中锁定的内容大纲和视觉规范，逐页生成完整的 16:9（或规格指定比例）PPT 页面图片。

每一页都必须重复提供：
1. 锁定的配色、字体气质、字号层级、网格、留白、图形语言、素材风格、页码样式和禁用项；
2. 当前页标题、准确正文、数字、单位、结论及来源约束；
3. 当前页页码和总页数；
4. 当前页允许出现的视觉对象与布局重点。

要求：
- 一次只生成当前页，不自行增删页面或改写已确认内容。
- 中文文字、数字、日期和单位必须准确，不得乱码、错字、漏字、重复、裁切或溢出。
- 不得为了美观删减关键事实，不得补充源材料没有的数据、人物或引语。
- 跨页保持同一视觉系统，但版式应服从各页内容，不机械复制同一网格。
- 文件按 01-title.png、02-title.png 的零填充格式保存。
- 当前页验收失败时只重做当前页，不连带重做已验收页面。

若同一页文字连续两次仍不准确，停止生图文字重试：生成不含标题、正文、数据标签和页码的无字背景，再按 overlay 规格程序化叠加准确文字，输出最终栅格页面。
```

### Prompt 2A：无字背景兜底

```text
为 {画布} 演示文稿生成当前页的无字视觉背景。
严格沿用 {锁定视觉规范}，保留 {不可移动的背景内容} 和为信息层预留的准确空间。
不得包含标题、正文、数字、数据标签、页码，或将在 Step 3 单独拆分的 {主体列表}。
不新增装饰，不改变已确认布局。
```

## Prompt 3：还原可编辑 PPTX

```text
以指定页面图片为唯一视觉基准，把页面还原为 Scene v1 并编译成可编辑 PPTX。保持原始页序、比例、文字、数据、排版、视觉重心和遮挡关系，不重新设计。

每次只处理 1–3 页：
1. 逐项识别文字、数据、几何、线条、表格、图表、图片主体、背景和遮挡；记录稳定 ID、整页像素坐标、层级、来源与置信度。
2. 标题、正文、数字、页码、简单形状/线、表格和有可靠数据的图表使用原生对象。
3. 照片、人物、产品和复杂插画作为独立图片对象；每个需要单独移动的视觉对象对应一个独立素材。
4. 从背景移除所有原生化文字与已拆出的主体，只补全露出的背景。主体分离与背景清理都从原始基准页开始，不串联编辑上一轮结果。
5. 原始整页图片只用于比对，不得放进可编辑版本充当底图；不得把整页 SVG 或截图加文本框称作完全可编辑。
6. 文字逐字转录；表格逐格录入；图表只使用可验证数值。无法确认的内容记入未解决项，不虚构、不省略。
7. 复杂插画内部仍是像素；被遮挡区域若由 AI 补全，明确记录补全范围。

完成每批后编译、审查并渲染，与基准图逐页对照。只修有问题的 Scene 元素或素材，保留其他稳定 ID、页序、样式和层级。
```

### Prompt 3A：独立主体

```text
以 {原始基准页} 为唯一参考，提取或重建 {元素 ID 与主体描述}。
保持身份、姿态、颜色、比例、光照和原始画布位置。输出真正带 alpha 的透明 PNG，只保留该主体及归属它的阴影/效果。
保持原画布尺寸；不得自动紧贴裁边，不添加文字、底板、棋盘格或其他对象。遮挡处只做最小补全并记录。
```

### Prompt 3B：背景清理

```text
以 {原始基准页} 为参考，从背景移除 {全部原生化文字、几何和独立主体 ID 清单}。
只补全移除后露出的背景，保持其余结构、纹理、光照、尺寸、颜色和留白。
不得重排布局、移动剩余对象、改写文字或新增内容。
```

### Prompt 3C：局部修改

```text
只修改 {slide-id}/{element-id} 的 {文字/颜色/几何/图表数据/素材}。
以现有 scene.json 和原始素材为基准，保留其他对象 ID、页序、样式和层级。
文字、几何或数据修改不重新生图；图片内容变化只重做对应素材，然后重新编译并审查受影响页面。
```
