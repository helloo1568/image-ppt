# 三阶段提示词

这些提示词只负责当前阶段的内容生成，不负责判断能否进入该阶段。阶段门禁以 `SKILL.md` 的状态机为准。

## Prompt 1：四套幻灯片浏览视图风格缩略图

```text
基于已经确认的源材料、使用场景和页数预期，先提炼一套逻辑完整、重点清晰的 PPT 内容大纲。

从完整大纲中选择同一组具有代表性的页面用于比较。建议包括封面、核心数据页、正文内容页、图表或结构页、案例页和总结/行动页。总页数不超过 8 页时，可以展示全部页面。

分别生成四张横向的“幻灯片浏览视图”风格缩略图。每张图代表一套完整设计方向，画面中以 3×2、4×2 或相近网格排列 6–8 张迷你 16:9 幻灯片，像 PowerPoint 的幻灯片浏览视图，而不是展示一张被缩小的单页。

四张风格缩略图必须使用完全相同的页面顺序、页面类型、标题、数据、内容结构和信息层级，只改变：
- 主题配色
- 字体气质
- 网格与排版方式
- 图形语言
- 图片、插画或材质风格

每张缩略图内部必须保持统一的母版、配色、字体、网格和图形语言，不得在一张图里混合多种风格。四套方案都应专业、美观、简洁，并适合已经确认的使用场景。如用户提供了参考模板，应以参考模板为基础做四种有区分度的演绎，不得偏离品牌识别。

不得为了制造风格差异而修改标题、数字、结论、页面数量或页面内容。生成后保留四张独立图片，分别编号为方案 1、方案 2、方案 3、方案 4。不要把四种风格再拼成一张 2×2 总览图。
```

## Prompt 2：生成完整图片版 PPT

```text
根据用户选定的风格方案和已确认的内容大纲，逐页生成完整的 16:9 PPT 页面图片。

先固定一份跨页视觉规范：主题色、辅助色、背景、字体气质、字号层级、网格、留白、图形语言、图片风格和页码样式。每一页都必须遵守该规范。

每次生成一页，并提供：
1. 固定视觉规范；
2. 当前页标题；
3. 当前页必须准确出现的文字、数字和结论；
4. 当前页的可视化建议；
5. 当前页页码和总页数。

每页突出一个主要观点，避免大段文字堆砌。不得虚构源材料没有的数据、案例、人物或引语。中文文字、数字、日期和单位必须准确，不得出现乱码、错字、漏字、重复文字、裁切或溢出。

完成全部页面后，检查跨页一致性和内容准确性。将全部页面图片按顺序嵌入 PowerPoint，输出图片版 PPTX，并保留逐页图片文件。
```

## Prompt 3：还原为可编辑 PPTX

```text
请把指定的图片版 PPT 页面还原成 16:9 的可编辑 PPTX。

采用“复杂视觉保真 + 主要信息可编辑”的混合策略：

1. 复杂视觉资产层
照片、人物、产品图、插画、3D 图、纹理、复杂背景、光影和复杂图表可裁切或提取为高清图片嵌入。

2. 可编辑信息层
标题、副标题、正文、关键数字、金句、结论框、页码、简单线条、基础形状、表格和简单图表使用 PPT 原生元素重建。

主要文字不得全部压缩为图片。匹配原图的字体气质、字号层级、字重、颜色、行距、对齐和位置。无法识别字体时，中文使用最接近的黑体、思源黑体或微软雅黑，英文使用相近的无衬线或衬线字体。

如原图已包含文字，先使用背景近似或局部遮罩覆盖原文字，再添加可编辑文本，避免重影。

保持原图的比例、视觉重心、阅读顺序、留白、颜色、对比度、裁切、圆角、描边、阴影和层级关系。复杂图表无法准确反推时可近似重建，但必须在交付说明中标注。

每次只处理 1–3 页。输出后渲染预览并与原图对照；发现明显的布局漂移、文字错误、裁切、溢出或视觉差异时继续修改。

交付时说明：
- 哪些元素可编辑；
- 哪些元素保留为图片；
- 是否存在字体替代；
- 是否存在图表或数据的近似重建。
```
